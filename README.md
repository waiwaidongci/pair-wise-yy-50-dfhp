# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 生产交接（版本 / 打样 / 导出联动）

领域逻辑集中在 `src/production/handoff.ts`（纯函数）与 `src/production/migration.ts`，不依赖 UI：

- **打样决定解锁版本**：每个 `ImpositionVersion` 记录 `unlockProofId`（由哪轮打样解锁）、父版本、内容哈希与锁定时刻快照。
- **新版本一变，旧结果对账**：锁定新版本时，所有旧导出任务按 2 页/组分片重算输入哈希（`reconcileTask`）：
  - 输入哈希与产物哈希仍匹配的分片 → 标记「复用 / 旧版本迁移」，进度保留；
  - 内容已变化的旧分片 → 标记「作废」并记录 `invalidatedByVersionId`；
  - 缺失分片 → 重新生成，运行中的任务回到「已中断」，从最后完成分片继续。
- **先确认者胜**：两个标签页几乎同时确认基线时（`commitBaseline`），以先到提交为生产基线，后到内容生成 `ConflictRecord`（含快照、内容/负载哈希）仅作留档，不覆盖数据；可一键载入为草稿后重新确认。跨标签页通过 `storage` 事件同步已确认基线。
- **写入失败恢复**：分片写入失败只落在失败组（`生成失败` + 错误信息 + 尝试次数），已完成分片与断点 `lastCompletedShardId` 保留，恢复时跳过已完成组。
- **旧数据迁移留哈希**：启动时按 `print-imposition-v1` → `print-imposition-v2` 迁移，`MigrationRecord` 保留源存档哈希、目标结构哈希与迁移分片数；内置样例同样生成一条「内置样例升级」哈希基线。
- **交付包血缘**：任务完成后生成包清单哈希；版本页与导出页可查看每个版本的解锁打样轮次、分片复用/作废去向和迁移哈希。

校验交接规则（17 项断言：迁移哈希、对账复用/作废、冲突留档、断点恢复）：

```bash
npm run verify:handoff
```
